- 上线 GitHub Pages：**https://whayeveoo-eng.github.io/territory-clash/**
- 决策：不推 31GB monorepo，给本游戏**单独建小仓库** `whayeveoo-eng/territory-clash`（96KB），main 分支根目录托管。

- 建项目骨架：模块化 src 目录 + docs 文档 + assets。

### 节奏分析与关键调参（同版本内）

- **发现僵局：** 初版 36×42（1512 格）+ 对称随机开火，跑 120s 仍卡在 50/50，炮台从不暴露，必平局。根因：36 列前线是独立随机游走，统计相互抵消，单格转化经济下滚雪球时间常数约 8 分钟。
- **决策——加 momentum：** 给炮台开火间隔按领地占比缩放（领地多→打得快→转化快→正反馈），把 50/50 从中性平衡变成不稳定平衡。这是为破僵局新增的机制，不属于最初与用户对齐的玩法，但不改「单格转化 / 随机角度 / 摧毁炮台获胜」的核心。
- **调参：** 格子 36×42→**24×28**（672）、开火间隔 24→**9**、炮台 HP 30→**22**、momentum `k=1.6 / [0.25, 2.6]`。
- **验证（30 局自动跑）：** 平均局长 `72s`（62-89s）、首次炮台受击 `~58s`、**0 平局**、全部「摧毁炮台」分胜负、金蓝胜率 `16:14`。S 形节奏：前 ~30s 拉锯、后段加速突破、收尾拆炮台。
- **冒烟测试通过：** 无控制台报错；开始/再来一局 UI 路径正常；转化、拉锯、推平暴露、摧毁结算、重置全部验证。
