# 领地炮战 TerritoryClash · 策划文档

## 一句话概念

竖屏棋盘由格子拼成，上下两方各有炮台自动开火；子弹飞入对方领域、把击中的第一个敌色格子转成己方色，前线来回拉锯；把前线推平、暴露并摧毁对方全部炮台者获胜。

## 灵感与参考

参考图 `未命名文件夹/IMG_0640.PNG`（抖音买量广告截图）：霓虹辉光风格，上半暖金、下半深蓝，中间一条锯齿霓虹线（= 前线），下方两个发光青色炮台。本项目取其**视觉风格**与**领地拉锯**结构，自定玩法机制。

这是仓库 `游戏项目开发说明.md` 中「领域 domain」概念的正向回归——在 HeavenVsHell 里领域是附属技能，这里领地是玩法主体。

## 第一版范围（v1 最小闭环）

- 一张 `1080×1260` 的格子棋盘，开局上半全金、下半全蓝，无中立格。
- 每方 2 个固定炮台，有 HP，自动持续开火。
- 子弹以随机角度射出，击中第一个敌色格子→转色→消失。
- 前线拉锯：格子可被双方反复转化，不锁定。
- 推平再暴露：炮台被己方格子当护甲，前方格子被清空后子弹才能命中炮台扣血。
- 胜负：摧毁对方全部炮台。
- 事件管线 + 节奏统计 + `window.__game` 测试钩子从第一版就接入。

## 暂不实现

- 底部三种武器切换（回旋镖曲线弹道、激光整列扫描）——留作后续配置入口。
- 玩家手动操作炮台（v1 纯自动对战，观赏向）。
- 道具、增益、护盾、可移动炮台、多于 2 炮台的阵型。
- 中立格、地形障碍、特殊格子（增益格 / 不可转化格）。
- 音效与 BGM（先留空目录）。

## 棋盘与对局参数

| 项 | 值 | 说明 |
| --- | --- | --- |
| 内部画布 | `1080 × 1260` | 竖屏，沿用仓库标准尺寸 |
| 格子 | `24 列 × 28 行`，每格 `45px` | 672 格。最初 36×42 太细，导致转化经济太慢、僵局难破，调到 672 后一局能在 ~70s 内分出胜负 |
| 开局领地 | 上 14 行金 / 下 14 行蓝 | 50/50 平分，中线即初始前线 |
| 炮台数 | 每方 2 个 | 固定在己方最外侧行附近 |
| 炮台 HP | `22` | 被敌方子弹直接命中 `-1`，归零摧毁。HP 决定暴露后的收尾时长 |
| 炮台开火间隔 | `~9 帧`（含抖动）× momentum 系数 | 见下「动态平衡」；两炮台错峰，避免齐射呆板 |
| 子弹速度 | `11 px/帧` | 小于格子边长，避免穿格 |
| 子弹半径 | `7 px` | |
| 出弹角度 | 朝对方半屏的随机角度（±60° 锥形内随机） | 「随机角度」需求：转化分布更乱、前线更犬牙交错 |

### 动态平衡：momentum（领地越多打得越快）

**为什么需要：** v1 第一版实测发现，单格转化 + 双方对称随机开火会形成**稳定僵局**——36 列前线各自是独立随机游走、统计上相互抵消，120s 后领地仍卡在 50/50，炮台永远暴露不出来，每局都超时平局。详见 [docs/changelog.md](changelog.md) v0.1.0 的节奏分析。

**机制：** 炮台每次开火后，按己方领地占比缩放下次开火间隔：

```
lead = (己方领地占比 − 0.5) × 2          // −1..1
间隔系数 = clamp(1 − k·lead, min, max)    // k=1.6, min=0.25, max=2.6
```

领地越多 → 间隔越短 → 开火越密 → 转化越快，形成正反馈。这让 50/50 成为**不稳定**平衡：早期小幅拉锯（观感悬念），一旦某方拿到领先就加速滚雪球突破，把对方推平、暴露炮台、收尾摧毁。

**实测（30 局自动跑）：** 平均局长 `72s`（区间 62-89s），全部由「摧毁全部炮台」分胜负、0 平局；金/蓝胜率约 `16:14`，无系统性偏向。

## 坐标与阵营约定（slot / team / color 分离）

- `y=0` 在顶部。**top 方**领地在上半（rows 0..20），炮台贴顶边，向下（+y）开火。
- **bottom 方**领地在下半（rows 21..41），炮台贴底边，向上（−y）开火。
- `top/bottom` 只表示出生侧；颜色（金 / 蓝）只表示视觉身份；team 只表示规则归属。三者通过数据配置关联，不写死「上方一定是金色」，支持后续 slot 互换与镜像局。

## 核心循环

1. 双方炮台按各自冷却自动开火，朝对方半屏随机角度发射子弹。
2. 子弹飞行：
   - 经过**己方色或同色格子**：穿过，无效果。
   - 进入对方领域、命中**第一个敌色格子**：该格转为己方色 → 前线推进 → 子弹消失。
   - 命中**敌方炮台**（仅当路径上已无敌色格子拦截时才可能发生）：炮台 `-1 HP`，子弹消失。
   - 飞出棋盘上下边界：消失；左右边界：反弹，留在场内。
3. 双方同时啃食边界，前线呈锯齿状来回拉锯。
4. 当某方把对方某炮台周围的护甲格全部转色后，子弹路径畅通 → 直接命中该炮台扣血直至摧毁。
5. 某方全部炮台被摧毁 → 对方获胜，结算。

## 推平再暴露（炮台保护机制）

炮台是独立于格子的对象，坐落在己方领地里。**炮台前方的己方色格子就是它的护甲**：

- 入射子弹遇到的第一个敌色格子会被转色并消失，因此只要炮台前方还有任何敌色（对炮台而言是己方色）格子，子弹就会先被它挡下，打不到炮台。
- 只有当进攻方把炮台前方的格子一路推平、转成进攻方色后，子弹飞行路径上不再有「敌色格子」拦截，才会继续飞到炮台位置并扣血。

这让「占领领地」与「摧毁炮台」自然联动：必须先赢得领地拉锯、压到对方家门口，才能开始拆炮台。

## 节奏目标（v1）

| 指标 | 建议目标 | v0.1.0 实测（30 局） |
| --- | --- | --- |
| 平均局长 | `60-90s` | `72s`（62-89s） |
| 前线有效转化 | 持续发生，肉眼可见来回拉锯 | ✓ S 形曲线，前 30s 拉锯、后段加速 |
| 首次炮台受击 | `45-65s`（需先推平） | `~58s` |
| 平局/超时率 | `< 10%` | `0%` |
| 单方胜率 | `35%-65%` 初期可接受 | 金 `53%` / 蓝 `47%` |

## 可扩展项（后续配置入口，不抢 v1 主目标）

- 武器系统：`回旋镖`（曲线/可回收弹道）、`激光`（整列扫描转化）。
- 玩家操作模式：手动选武器 / 手动瞄准。
- 特殊格子：增益格、不可转化格、可吃回血格。
- 炮台升级：射速、多发、护盾、可移动。
- 多于 2 炮台、非对称阵型、3 方混战。
- slot 互换与镜像对局的自动节奏测试。
