# 领地炮战 TerritoryClash · 美术文档

## 整体风格

霓虹辉光（neon glow），纯深色底 + 高饱和发光元素 + 辉光描边，对标参考图 `IMG_0640.PNG`。竖屏短视频友好，画面中心留给前线拉锯。

## 配色

| 元素 | 主色 | 辉光 | 说明 |
| --- | --- | --- | --- |
| 背景 | `#05060a` | — | 近黑深蓝，衬托辉光 |
| top 方（金）领地格 | `#f5a623` | `#ffd36b` | 暖金 |
| bottom 方（蓝）领地格 | `#1f7cff` | `#5bd6ff` | 青蓝 |
| 前线高亮 | 白 `#ffffff` | 沿用两方色 | 锯齿边界发光描边 |
| 子弹 | 跟随所属方色 | 同色加亮 | 小圆点 + 短拖尾 |
| 炮台 | 跟随所属方色 | 同色光晕 | 圆形核心 + 顶部小柄（呼应参考图） |
| 炮台受击 | 闪白 | — | 命中瞬间高光 |

颜色对比足够（暖金 vs 青蓝），不依赖红绿，照顾色弱。

## 格子棋盘

- 格子之间留 `1-2px` 暗缝，弱网格感，不抢主视觉。
- 同色大片区域可整体绘制 + 边缘辉光，避免逐格描边过噪。
- 前线（两色相邻处）加白色辉光描边，强调锯齿拉锯，这是画面焦点。

## 炮台

- 圆形发光核心 + 顶部短柄（参考图的发光球造型）。
- HP 用环形/小条表示，或核心亮度随 HP 衰减。
- 被推平暴露后可加「警示」呼吸光，提示即将被拆。

## 动效优先级

1. 格子转化（前线推进的逐格闪光）。
2. 炮台受击与摧毁。
3. 子弹飞行拖尾。
4. 左右墙反弹。
5. 胜利结算氛围。

转化闪光要清楚但不能糊成一片；炮台摧毁要有明显爆破，但不遮挡领地占比读数。

## UI

- 外部 UI 尽量少：顶部一条领地占比条（金/蓝双色比例）+ 极简标题。
- 开始按钮、结算层适合手机竖屏点击。
- 文案只说必要状态（开始 / 胜负 / 占比），不写长段玩法说明。
